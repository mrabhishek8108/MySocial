# MySocial Complete MVP
Upload these files to the GitHub Pages repository.

## Real worldwide mode
Create a Supabase project, run `supabase.sql`, then put the project's public URL and anon key in `config.js`. Never put a service_role/secret key in browser code.

## Included
Authentication, profiles, posts/feed, likes, follow/unfollow, search, stories UI, notifications/messages placeholders, PWA files, RLS database schema.

## Still required before public launch
Media storage/upload policies, realtime chat, real comments UI, moderation/report/block flows, rate limiting/anti-spam, account deletion/privacy tooling, analytics, legal pages, backups, domain, ads/payment provider approval, and Play Store packaging/testing.

## Monetization
Possible models include advertising, sponsored content, business promotion, creator subscriptions and gifts. Revenue is not automatic; users and engagement are needed first.
